# NyzeVPN — сайт

Статический сайт (HTML/CSS/JS), готовый для GitHub Pages.

## Структура

```
index.html      главная страница
css/style.css   стили и декор
js/main.js      анимации при скролле
img/flags/      SVG-флаги стран (для серверов)
CNAME           файл с вашим доменом (создаётся на шаге 5)
```

---

## Туториал: публикация на GitHub Pages с своим доменом

### Шаг 1. Создайте репозиторий на GitHub

1. Зайдите на https://github.com и войдите в аккаунт (или зарегистрируйтесь).
2. Нажмите **+** → **New repository**.
3. Название, например: `nyzevpn-site`.
4. Выберите **Public** (для бесплатных GitHub Pages репозиторий должен быть публичным).
5. Нажмите **Create repository**.

### Шаг 2. Загрузите файлы

**Вариант А — через браузер (проще всего):**

1. Распакуйте архив `nyzevpn-site.zip` на компьютере.
2. В репозитории нажмите **uploading an existing file**.
3. Перетащите все файлы и папки (`index.html`, `css/`, `js/`, `README.md`).
4. Нажмите **Commit changes**.

**Вариант Б — через git в терминале:**

```bash
cd путь/к/папке/nyzevpn-site
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/nyzevpn-site.git
git push -u origin main
```

### Шаг 3. Включите GitHub Pages

1. Откройте репозиторий → **Settings** → вкладка **Pages** (слева).
2. В разделе **Build and deployment** → **Source** выберите **Deploy from a branch**.
3. **Branch**: `main`, папка: `/ (root)`. Нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/nyzevpn-site/`

### Шаг 4. Купите домен

Домен можно купить у любого регистратора, например REG.RU, Timeweb, Namecheap, Porkbun или Cloudflare Registrar. Нужен домен вида `nyzevpn.ru` или `nyzevpn.com`.

### Шаг 5. Привяжите домен к GitHub Pages

**5.1. Создайте файл `CNAME`**

В корне репозитория создайте файл с именем `CNAME` (без расширения), внутри одна строка — ваш домен без `https://`:

```
nyzevpn.com
```

Загрузите его в репозиторий (Add file → Upload files или через git). Либо в **Settings → Pages → Custom domain** введите домен и нажмите **Save** — GitHub создаст файл сам.

**5.2. Настройте DNS у регистратора**

Зайдите в панель управления доменом → раздел **DNS** и добавьте записи.

Для корневого домена (`nyzevpn.com`) добавьте **четыре записи типа A**:

| Тип | Имя/Host | Значение           |
|-----|----------|--------------------|
| A   | @        | 185.199.108.153    |
| A   | @        | 185.199.109.153    |
| A   | @        | 185.199.110.153    |
| A   | @        | 185.199.111.153    |

Для поддомена `www` добавьте запись:

| Тип   | Имя/Host | Значение                |
|-------|----------|-------------------------|
| CNAME | www      | ВАШ_ЛОГИН.github.io     |

Если у регистратора есть AAAA-записи для GitHub, их можно добавить (IPv6):
`2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153`.

**5.3. Включите HTTPS**

1. Вернитесь в **Settings → Pages**.
2. Введите домен в **Custom domain** и нажмите **Save**.
3. DNS может обновляться от нескольких минут до 24 часов. Когда появится зелёная галочка DNS check successful, отметьте **Enforce HTTPS**.

Готово. Сайт открывается по адресу `https://nyzevpn.com`.

### Частые проблемы

- **Страница 404** — проверьте, что файл называется именно `index.html` в корне и что выбрана ветка `main` и папка `/ (root)`.
- **Домен не открывается** — подождите, DNS обновляется долго. Проверить можно командой `nslookup nyzevpn.com`.
- **Нет зелёной галочки в Pages** — убедитесь, что в CNAME-файле нет лишних пробелов и `https://`.
- **Стили не применились** — проверьте, что папки `css/` и `js/` загружены с теми же именами.
